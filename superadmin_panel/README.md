# E-MAKON SuperAdmin Panel

Next.js (App Router) + Tailwind v4 — Stitch [Verdant Admin](https://stitch.withgoogle.com/projects/1160786752279132216) dizayni.

## Ishga tushirish

```powershell
cd D:\Cloude\projects\e-makon\superadmin_panel
npm install
npm run dev
```

→ http://localhost:3000
